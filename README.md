# 🍽️ What2Eat

Can't decide what to eat? Spin the wheel!

**Play it live:** https://barrystlow.github.io/what2eat/

## Features
- 🎡 Spin-the-wheel food picker
- 6 presets: Fast Food, Healthy, Asian, Italian, Breakfast, Desserts
- ➕ Add your own options (saved in your browser)
- 📍 "Find Nearby" button opens Google Maps for the winner

## Tech
Pure HTML, CSS and JavaScript — no frameworks, no build tools.
